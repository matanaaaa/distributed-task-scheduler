项目名称：分布式数据同步与任务调度平台

技术栈：Go、Gin、Redis、MySQL、Docker Compose

项目描述：面向大规模 MySQL 数据迁移与异构系统同步场景，自主设计并实现分布式任务调度与数据同步平台。系统支持全量/增量同步、任务分片、并发消费、断点续传、失败重试、死信队列及数据一致性校验，提高批量数据处理的可靠性与可扩展性。

核心工作：

基于 Redis 优先级队列和有界 Worker Pool 实现分布式任务调度，支持 Worker 横向扩容、任务状态流转及运行进度聚合。

设计全量同步分片机制，根据主键范围生成互不重叠且完整覆盖的数据分片，实现多 Worker 并行处理。

实现基于“时间水位 + 主键”的复合游标增量同步，通过 Keyset Pagination 避免 OFFSET 深分页带来的性能问题。

采用批量读取、批量 Upsert 和 Checkpoint 持久化机制，实现任务中断后的断点续传，并利用目标端幂等写入降低重复消费影响。

建立可重试、不可重试与任务取消等错误分类机制；对临时数据库异常执行重试，对脏数据进行隔离和溯源记录，避免单条异常阻塞整个同步任务。

实现 Count 与字段级 Checksum 数据对账，通过归并比较定位源端缺失、目标端多余及字段不一致记录。

支持字段映射、类型转换、常量填充、手机号脱敏和 SHA-256 散列等数据转换规则，并通过单元测试覆盖分片边界、状态机、增量游标和对账算法。
